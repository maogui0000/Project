### 3.2 長者資料頁

顯示 `elder_profile` 所有欄位，分區塊：
- 個人資訊（姓名、慣稱、性別、年齡、居住地）
- 緊急聯絡人
- 醫療安全（慢性疾病、用藥、過敏）
- 身體照護（行動能力、飲食禁忌）
- 認知狀態
- 感官偏好（聽力、語言）
- 興趣話題

每個區塊右上角有「✏️ 編輯」按鈕，點擊彈出編輯 modal。

## 4. 前端技術實作

### 4.1 單頁應用（SPA）路由

使用 hash-based routing（不需要後端路由支援）：

```javascript
const routes = {
  '#home': renderHomePage,
  '#profile': renderProfilePage,
  '#summary': renderSummaryPage,
  '#emotion': renderEmotionPage,
  '#stats': renderStatsPage,
  '#timeline': renderTimelinePage,
  '#reminders': renderRemindersPage,
  '#settings': renderSettingsPage,
};

window.addEventListener('hashchange', () => {
  const page = location.hash || '#home';
  routes[page]?.();
  updateActiveNav(page);
});
```

### 4.2 資料載入

Dashboard 所有頁面共用同一份 API 資料：

```javascript
let elderData = null;

async function loadElderData() {
  const resp = await fetch(`/api/elder/${elderId}`, {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  elderData = await resp.json();
  renderCurrentPage();
}
```

### 4.3 即時更新（SSE）

訂閱 `/api/elder/events/stream`，收到事件時即時更新對應區塊：

```javascript
const evtSource = new EventSource('/api/elder/events/stream');
evtSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  if (data.type === 'summary_updated') refreshSummary();
  if (data.type === 'speech_interaction') refreshTimeline();
};
```

## 5. 與留言板整合

Dashboard 首頁 SHALL 顯示未讀留言計數：

```javascript
async function checkMessages() {
  const resp = await fetch(`/api/messages/${elderId}/unread`);
  const data = await resp.json();
  if (data.unread_count > 0) {
    showBadge('messages', data.unread_count);
  }
}
```
